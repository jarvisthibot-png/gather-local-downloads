# Pixellar — downloads

Aplicativo para salas privadas entre amigos, com mapa 2D, voz e compartilhamento de tela. Os dados ficam nos computadores dos participantes.

[Baixar a versão mais recente](https://github.com/jarvisthibot-png/gather-local-downloads/releases/latest)

## Versão atual: 0.3.1-dev.6 (teste)

A janela flutuante está temporariamente desativada. O áudio Windows → Mac ainda precisa de diagnóstico e confirmação; esta entrega não é uma versão estável validada.

- **Windows 10/11 x64:** baixe `Pixellar-0.3.1-dev.6-windows-x64.exe`. O ZIP é uma alternativa; extraia a pasta completa antes de executar.
- **Mac Apple Silicon:** baixe o PKG `arm64`.
- **Mac Intel:** baixe o PKG `x64`.
- **macOS mínimo:** 14.2. DMG e ZIP são alternativas ao PKG.

A instalação conserva a pasta técnica `gather-local` e o identificador do app. Faça backup antes de atualizar. As confirmações normais do Gatekeeper, SmartScreen e Acesso às Chaves podem aparecer porque não há certificado comercial/notarização nesta distribuição.

O manifesto assinado `update.json`, `SHA256SUMS.txt` e as notas acompanham a release. Versões com atualizador também permitem verificar e baixar pelo próprio app. Este repositório contém somente instruções e pacotes de distribuição, sem bancos, backups, chaves ou código do projeto.

## Verificação

Testes de interface e desativação da flutuante executados no Mac Apple Silicon. Pacotes Intel/Windows compilados no Mac, sem execução ou instalação verificada nesses sistemas nesta entrega.
