# Gather Local — downloads oficiais

Baixe instaladores estáveis do Gather Local pela página [Releases](https://github.com/jarvisthibot-png/gather-local-downloads/releases). O aplicativo é privado por convite e salva os dados no computador dos participantes.

## Instalação

- **Windows 10/11 x64:** baixe o instalador EXE da versão mais recente e siga o assistente.
- **macOS Intel / Apple Silicon:** baixe o instalador PKG correspondente ao processador. DMG e ZIP são alternativas. O primeiro uso em uma versão anterior à 0.3.0 exige instalação manual.

O manifesto assinado update.json, as notas e os hashes SHA-256 acompanham cada versão. O Windows SmartScreen e o Gatekeeper podem apresentar avisos porque os pacotes não têm certificado comercial nesta etapa.
